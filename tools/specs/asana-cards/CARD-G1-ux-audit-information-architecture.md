
## Description

```text
## Objective

Review the current web app as a set of user journeys, prioritize usability problems,
and define the page structure and content hierarchy for the redesign.

## Acceptance Criteria

- [ ] Review home, dashboard, transaction list, create and edit flows
- [ ] Record friction points with route and user impact
- [ ] Define navigation for Visão geral, Transações and Nova transação
- [ ] Define the primary path for adding a transaction and the manual fallback
- [ ] Define empty, loading, error, success and refreshing states by page
- [ ] Use the PocketFinance HTML concept as a reference and note accepted changes
- [ ] Record the proposed journey and decisions in SPEC-011

## Full Spec

tools/specs/SPEC-011-epic-g-web-product-experience.md
```

## Subtasks

```text
1. Walk through current routes at desktop and mobile widths
2. List the top UX problems and their effect on user tasks
3. Define the navigation model and primary actions
4. Map each page's data, empty state and recovery path
5. Review the direction with the Tech Lead and update SPEC-011
```
